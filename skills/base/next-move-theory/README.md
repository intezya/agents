# Next Move Theory

Codex variants of the public Next Move Theory skills and their required canon.
Imported from `zamesin/Next-Move-Theory-Canon-and-Skills` commit `259bc127b2732ca3e19387ea91956c64b3347dc6`.

## Manual Codex installation

Copy the seven `nmt-*` directories and the two contracts to `~/.codex/skills/`, then copy `Next-Move-Theory-Canon/` to `~/.codex/`. Do not run the upstream installer: it mutates project instruction files.

The skills first use a project-local `Next-Move-Theory-Canon/`; if it is absent, they use `~/.codex/Next-Move-Theory-Canon/`.
